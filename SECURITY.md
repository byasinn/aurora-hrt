# Segurança

O Aurora roda em produção com dados reais de pessoas trans, incluindo informação de saúde. Se você
encontrar uma vulnerabilidade — na instância em produção (aurorahrt.com.br) ou em algo genérico no
código deste repositório — **não abra uma Issue pública**.

Reporte em privado: [byasinn](https://github.com/byasinn) (via um Issue do GitHub marcado como
[security advisory](https://github.com/byasinn/aurora-hrt/security/advisories/new), que fica
privado por padrão) ou pelo email do perfil do GitHub.

Inclua o máximo de detalhe possível: passos pra reproduzir, impacto potencial, e se possível uma
sugestão de correção. Sem prazo formal de resposta (é um projeto pessoal), mas relatos envolvendo
exposição de dado de usuário real têm prioridade máxima.
